Employee Average Salary Calculator

This is a simple C++ program that demonstrates the use of classes, objects, member functions, arrays, and basic calculations.

📌 Features
Stores employee name
Stores employee designation
Stores employee salary
Accepts details for 5 employees
Calculates and displays the average salary
🛠️ Concepts Used
C++
Classes and Objects
Member Functions
Arrays of Objects
Functions
Loops
Encapsulation
▶️ How It Works
Enter the details of 5 employees.
The program stores their salaries.
It calculates the total salary.
The total is divided by 5.
The average salary is displayed.
